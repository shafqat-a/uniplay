# Apple Music Adapter Contract

**Service**: Apple Music API (MusicKit)
**Library**: Custom HttpClient wrapper
**Authentication**: Developer JWT (ES256) + User Music Token
**Documentation**: https://developer.apple.com/documentation/applemusicapi

## Authentication Flow

### Two-Stage Authentication

Apple Music uses a unique authentication model:

1. **Developer Token** (JWT signed with ES256)
   - Generated by backend using private key
   - Valid for up to 6 months
   - Used for all API requests

2. **User Music Token**
   - Obtained via MusicKit JS on frontend
   - Represents user authorization
   - Included in API requests for user-specific data

### Developer Token Generation

```csharp
public class AppleMusicTokenGenerator
{
    private readonly string _teamId;
    private readonly string _keyId;
    private readonly ECDsa _privateKey;

    public string GenerateDeveloperToken()
    {
        var securityKey = new ECDsaSecurityKey(_privateKey) { KeyId = _keyId };

        var credentials = new SigningCredentials(
            securityKey,
            SecurityAlgorithms.EcdsaSha256
        );

        var descriptor = new SecurityTokenDescriptor
        {
            Issuer = _teamId,
            Audience = "applemusicapi",
            Expires = DateTime.UtcNow.AddMonths(6),
            IssuedAt = DateTime.UtcNow,
            SigningCredentials = credentials
        };

        var handler = new JwtSecurityTokenHandler();
        var token = handler.CreateToken(descriptor);
        return handler.WriteToken(token);
    }
}
```

### OAuth Configuration

- **Developer Account**: Apple Developer Program membership required ($99/year)
- **MusicKit Identifier**: Register at https://developer.apple.com/account/resources/identifiers
- **Private Key**: Download .p8 file from Apple Developer portal
- **Frontend Integration**: MusicKit JS for user authorization

## Rate Limiting

### Limits
- **Rate Limit**: Not publicly documented (Apple uses adaptive rate limiting)
- **Best Practice**: 120 requests per minute per user token
- **Batch Operations**: Supported (up to 300 IDs per request)

### Implementation
```csharp
services.AddHttpClient<IAppleMusicAdapter, AppleMusicAdapter>(client =>
{
    client.BaseAddress = new Uri("https://api.music.apple.com/v1/");
    client.DefaultRequestHeaders.Add("Music-User-Token", "{userMusicToken}");
    client.DefaultRequestHeaders.Add("Authorization", $"Bearer {developerToken}");
})
.AddResilienceHandler("applemusic", builder =>
{
    builder.AddRetry(new HttpRetryStrategyOptions
    {
        MaxRetryAttempts = 3,
        BackoffType = DelayBackoffType.Exponential,
        UseJitter = true
    });

    builder.AddCircuitBreaker(new HttpCircuitBreakerStrategyOptions
    {
        FailureRatio = 0.5,
        SamplingDuration = TimeSpan.FromSeconds(30),
        BreakDuration = TimeSpan.FromSeconds(30)
    });
});
```

## Data Mapping

### Playlist Mapping
```csharp
ServicePlaylistDto MapPlaylist(AppleMusicPlaylist appleMusicPlaylist)
{
    return new ServicePlaylistDto
    {
        ServicePlaylistId = appleMusicPlaylist.Id,
        Name = appleMusicPlaylist.Attributes.Name,
        Description = appleMusicPlaylist.Attributes.Description?.Standard,
        ServiceOwnerId = appleMusicPlaylist.Attributes.CuratorName ?? "unknown",
        IsOwnedByUser = appleMusicPlaylist.Attributes.CanEdit,
        TrackCount = appleMusicPlaylist.Attributes.TrackCount,
        ImageUrl = appleMusicPlaylist.Attributes.Artwork?.Url
            .Replace("{w}", "600")
            .Replace("{h}", "600"),
        ServiceUrl = appleMusicPlaylist.Attributes.Url
    };
}
```

### Track Mapping

## Error Handling

### Apple Music API Errors
| Status Code | Error | UniPlay Handling |
|-------------|-------|------------------|
| 401 | Unauthorized | Invalid developer or user token → Regenerate/refresh |
| 403 | Forbidden | User lacks Apple Music subscription → Mark connection as Error |
| 404 | Not Found | Playlist deleted → Update SyncStatus to Deleted |
| 429 | Too Many Requests | Exponential backoff → Queue for retry |
| 500, 503 | Server Error | Retry with backoff |

### Example Implementation
```csharp
public async Task<ServicePlaylistDto> GetPlaylistAsync(string userMusicToken, string playlistId)
{
    var request = new HttpRequestMessage(
        HttpMethod.Get,
        $"me/library/playlists/{playlistId}"
    );

    request.Headers.Add("Music-User-Token", userMusicToken);
    request.Headers.Add("Authorization", $"Bearer {_developerToken}");

    try
    {
        var response = await _httpClient.SendAsync(request);

        if (response.StatusCode == HttpStatusCode.Unauthorized)
        {
            // Regenerate developer token if expired
            _developerToken = GenerateDeveloperToken();
            throw new TokenExpiredException("Apple Music developer token expired");
        }

        if (response.StatusCode == HttpStatusCode.Forbidden)
        {
            throw new ServiceAuthorizationException(
                "User lacks Apple Music subscription or permissions");
        }

        response.EnsureSuccessStatusCode();

        var content = await response.Content.ReadAsStringAsync();
        var data = JsonSerializer.Deserialize<AppleMusicResponse<AppleMusicPlaylist>>(content);

        return MapPlaylist(data.Data.First());
    }
    catch (HttpRequestException ex)
    {
        throw new MusicServiceException("Apple Music API error", ex);
    }
}
```

## Track Matching

### ISRC Matching (Preferred)
```csharp
public async Task<TrackDto?> FindTrackByISRCAsync(string userMusicToken, string isrc)
{
    var request = new HttpRequestMessage(
        HttpMethod.Get,
        $"catalog/us/songs?filter[isrc]={isrc}"
    );

    request.Headers.Add("Authorization", $"Bearer {_developerToken}");

    var response = await _httpClient.SendAsync(request);
    response.EnsureSuccessStatusCode();

    var content = await response.Content.ReadAsStringAsync();
    var data = JsonSerializer.Deserialize<AppleMusicResponse<AppleMusicTrack>>(content);

    return data.Data?.FirstOrDefault() != null
        ? MapTrack(data.Data.First())
        : null;
}
```

### Metadata Search
```csharp
public async Task<IEnumerable<TrackDto>> SearchTracksAsync(
    string userMusicToken,
    string query,
    int limit = 25)
{
    var encodedQuery = Uri.EscapeDataString(query);
    var request = new HttpRequestMessage(
        HttpMethod.Get,
        $"catalog/us/search?types=songs&term={encodedQuery}&limit={limit}"
    );

    request.Headers.Add("Authorization", $"Bearer {_developerToken}");

    var response = await _httpClient.SendAsync(request);
    response.EnsureSuccessStatusCode();

    var content = await response.Content.ReadAsStringAsync();
    var data = JsonSerializer.Deserialize<AppleMusicSearchResponse>(content);

    return data.Results.Songs?.Data?.Select(MapTrack) ?? Enumerable.Empty<TrackDto>();
}
```

## Frontend Integration (MusicKit JS)

Users must authorize via MusicKit JS on the frontend before connecting Apple Music:

```javascript
// Frontend: Initialize MusicKit
const music = await MusicKit.configure({
  developerToken: developerToken, // From backend
  app: {
    name: 'UniPlay',
    build: '1.0.0'
  }
});

// Authorize user
const userMusicToken = await music.authorize();

// Send userMusicToken to backend
await fetch('/api/v1/service-connections/callback', {
  method: 'POST',
  body: JSON.stringify({
    serviceType: 'AppleMusic',
    userMusicToken: userMusicToken
  })
});
```

## Storefront (Region) Handling

Apple Music is region-specific. Track availability varies by storefront.

```csharp
public async Task<string> GetUserStorefrontAsync(string userMusicToken)
{
    var request = new HttpRequestMessage(HttpMethod.Get, "me/storefront");
    request.Headers.Add("Music-User-Token", userMusicToken);
    request.Headers.Add("Authorization", $"Bearer {_developerToken}");

    var response = await _httpClient.SendAsync(request);
    var content = await response.Content.ReadAsStringAsync();
    var data = JsonSerializer.Deserialize<AppleMusicResponse<AppleMusicStorefront>>(content);

    return data.Data.First().Id; // e.g., "us", "gb", "jp"
}

// Use storefront in search queries
var storefrontId = await GetUserStorefrontAsync(userMusicToken);
var searchUrl = $"catalog/{storefrontId}/search?types=songs&term={query}";
```

## Pagination

Apple Music uses offset-based pagination with a maximum of 100 items per request.

```csharp
public async Task<IEnumerable<ServicePlaylistDto>> GetAllUserPlaylistsAsync(string userMusicToken)
{
    var allPlaylists = new List<ServicePlaylistDto>();
    var offset = 0;
    const int limit = 25;
    string nextUrl = $"me/library/playlists?limit={limit}";

    while (!string.IsNullOrEmpty(nextUrl))
    {
        var request = new HttpRequestMessage(HttpMethod.Get, nextUrl);
        request.Headers.Add("Music-User-Token", userMusicToken);
        request.Headers.Add("Authorization", $"Bearer {_developerToken}");

        var response = await _httpClient.SendAsync(request);
        var content = await response.Content.ReadAsStringAsync();
        var data = JsonSerializer.Deserialize<AppleMusicResponse<AppleMusicPlaylist>>(content);

        allPlaylists.AddRange(data.Data.Select(MapPlaylist));

        nextUrl = data.Next; // Apple Music provides next URL
    }

    return allPlaylists;
}
```

## Limitations

- **Subscription Required**: Users must have active Apple Music subscription
- **No Reordering**: Apple Music API does not support track reordering
- **Limited Batch Operations**: Maximum 300 items per batch request
- **Regional Differences**: Track availability varies by storefront
- **Developer Program Cost**: $99/year Apple Developer Program membership required
